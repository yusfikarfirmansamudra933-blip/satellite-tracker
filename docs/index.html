Pelacak satelit buatan sendiri

Mount pan-tilt yang menghitung posisi satelit seperti ISS, Tiangong, dan satelit cuaca, lalu mengarahkan penunjuk tepat ke satelit itu di langit, secara real-time.

Cara kerja

🎯 Akurat

Posisi yang dihitung ESP32 dibandingkan dengan library astronomi Skyfield: selisih di bawah 0,05°.

🔄 Ikut terus

Pan selalu mengikuti arah satelit, bahkan saat satelit di sisi lain bumi. Kabel tidak terpelintir berkat putar balik otomatis.

📡 Tanpa internet di lapangan

GPS memberi lokasi dan waktu. Internet hanya perlu sesekali untuk memperbarui data orbit.

📱 Kontrol dari HP

ESP32 memancarkan WiFi sendiri. Buka 192.168.4.1 untuk peta langit, jadwal lintasan, dan kalibrasi.

Komponen

Elektronik

  • ESP32 DevKit
  • 2× motor stepper 28BYJ-48 + 2× driver ULN2003
  • 1× IC 74HC595 (shift register)
  • Modul GPS NEO-6M (opsional)
  • Power supply 5V 2A, kapasitor 100–470µF

Mekanik

  • Bracket pan-tilt
  • Penunjuk: panah atau sedotan (jangan laser)
  • Kabel motor tilt dibuat kendur untuk 1,5 putaran

Cara pakai

  1. Upload firmware dengan VS Code + PlatformIO: buka folder proyek, klik ✓ (Build), lalu → (Upload).
  2. Sambungkan HP ke WiFi SatTracker (password satelit123), lalu buka http://192.168.4.1.
  3. Isi WiFi internet agar ESP32 bisa mengunduh data orbit dan jam. Tanpa GPS, isi juga Lokasi cadangan.
  4. Kalibrasi: arahkan penunjuk ke utara dan datar memakai kompas HP, lalu tekan Set utara dan Set datar. Uji dengan GOTO azimuth 90° (harus ke timur).
  5. Pilih satelit lalu tekan TRACK. Penunjuk terus mengikuti satelit. Lintasan bertanda 👁 bisa dilihat dengan mata.

Batasan

  • Lintasan tepat di atas kepala (elevasi > ~80°) bergerak lebih cepat dari batas 28BYJ-48 (±60°/s), jadi penunjuk sempat tertinggal.
  • Gearbox 28BYJ-48 punya backlash 1–3°: cukup untuk penunjuk visual, kurang untuk antena yang sangat terarah.
  • Data orbit (TLE) sebaiknya diperbarui seminggu sekali.
Data orbit dari CelesTrak. Perhitungan orbit di ESP32 memakai library Sgp4. Pelacak online memakai satellite.js.
